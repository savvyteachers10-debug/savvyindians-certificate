# Savvy Indians – Generative AI Workshop Certificates

Live site: https://savvyteachers10-debug.github.io/savvyindians-certificate/

Students open the link, enter their full name, press **Generate My Certificate**
and download an A4 landscape PDF. Everything runs in the browser: no server,
no database, no paid service.

## Change the date, signatory or design
Edit the `SETTINGS` block near the top of `index.html` on GitHub
(pencil icon → edit → **Commit changes**). The site updates in about a minute.

## Files
- `index.html` – the complete app (fonts, logos and signature are built in)
- `source/` – editable source; `python3 source/build.py` rebuilds `source/dist/index.html`

Fonts (Cinzel, Cormorant Garamond, Great Vibes, Montserrat) are under the SIL Open Font License, see `source/fonts/OFL-license.txt`.
